---

## 📌 Project Overview
AtliQ Hardware is facing challenges in tracking business performance across different departments. This Power BI project provides a single platform - **Business Insights 360** - with 5+ interactive dashboards to help executives make data-driven decisions.


> **Compliance Note:** This repository contains only dashboard screenshots. No raw dataset, CSV, or Excel files are published. Dataset is owned by Codebasics.io and used only for learning, in compliance with their terms.

### 🎥 Project Demo
As shown in the attached screenshots, the project contains a fully interactive Power BI dashboard with navigation from Home Page to all business views.

## 🏠 Dashboard Views

### 1. Home Page - Business Insights 360
- Central landing page with 7 navigation buttons
- Buttons: Info, Finance View, Sales View, Marketing View, Supply Chain View, Executive View, etc.
- Clean UI with AtliQ Hardware branding and icons
- One-click navigation using Power BI Bookmarks

### 2. Finance View
- **KPIs:** Net Sales, COGS, Gross Margin, GM%
- **Visuals:** P&L Trend by Month, Performance Comparison
- **Insights:** Top & Bottom 5 Products / Customers by Gross Margin
- **Features:** Filter by Fiscal Year, Market, Division

### 3. Sales View
- **KPIs:** Total Revenue, Profit, Sales Quantity
- **Visuals:** Customer Performance table, Sales Trend Analysis
- **Insights:** Market Performance vs Target, Customer-wise breakdown

### 4. Product View
- **Insights:** Product Performance by Revenue & Profit
- **Visuals:** Top products, Product growth analysis
- Used for identifying best and worst performing products

### 5. Marketing View
- **Visuals:** Product Performance Matrix, Market Share, Customer Performance
- **Charts:** Scatter plot (Performance Matrix), Donut charts for Share
- **Insights:** Market-wise customer performance, Product positioning
- **As seen in video (0:31):** Marketing metrics with Forecast Accuracy

### 6. Supply Chain View
- **KPIs:** Forecast Accuracy, Net Error, Risk, OTIF, Inventory
- **Visuals:** Bar chart for Forecast Accuracy over Time, Top Products by Forecast Accuracy
- **As seen in video (0:52):** Detailed tables for Forecast vs Actual, Risk classification
- **Business Value:** Helps reduce stock-outs and excess inventory

## 🛠️ Technical Stack

| Component | Details |
| :--- | :--- |
| **Tool** | Power BI Desktop |
| **Data Transformation** | Power Query |
| **Data Modeling** | Star Schema, Relationships, Date Table |
| **DAX** | Measures for GM%, Forecast Accuracy, Net Error, OTIF, YOY Growth, SUMX, CALCULATE |
| **Visuals** | Bar, Line, Scatter, Donut, Cards, Matrix, Tables |
| **Navigation** | Bookmarks, Page Navigation Buttons, Tooltips |
| **Design** | Consistent theme, HP laptop optimized layout |

---

## 💡 Key Business Insights

1.  **Finance:** Identified markets with low GM% needing cost optimization
2.  **Sales:** USA and India contribute highest revenue; small customers show high growth potential
3.  **Marketing:** Forecast Accuracy varies by market - Opportunity to improve in LATAM
4.  **Supply Chain:** High Net Error for certain products leading to overstock - Need to improve forecasting

## 📂 How to Navigate

3.  All reports have filters for Fiscal Year, Market, and Division
